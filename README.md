# ALLABOUTNEPAL

A web-based ALLABOUTNEPAL designed to promote and preserve the rich cultural heritage of Nepal. This platform provides users with detailed information about heritage sites, festivals, cultural events, and interactive features such as quizzes, reviews, maps, and multimedia content.

## Features
### Heritage Sites Information  
Detailed descriptions, image galleries, videos, and locations  
Google Maps integration with latitude & longitude  

### Festivals & Cultural Events  
Festival calendar with upcoming events  
Countdown and category-based filtering  

### Review & Rating System  
User reviews with star ratings  
Average rating and review count display  
Admin moderation support  

### Gamified Quiz Section  
Category-based cultural quizzes  
Score tracking, leaderboard, and achievements  
User quiz history and progress tracking  

### Text-to-Speech Support  
Audio narration in English and Nepali  

### User Profile System  
Editable user profile with photo upload  
Quiz history and performance tracking  

### Admin Dashboard  
Manage heritage sites, festivals, quizzes, reviews, and users  
Media uploads (images & videos)  

### Responsive Design  
Fully mobile-friendly UI
